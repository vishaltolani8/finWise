# FinWise — AI Powered Financial Education Platform

FinWise is a smart expense tracking and financial education mobile application built with Flutter. The platform helps users learn saving, investing, budgeting, and wealth-building through AI-powered personalized insights and financial analytics. 

> 🚧 **Project Status:** Currently under development (~60% completed)

---

## Features

* Expense & Income Tracking
* Financial Analytics Dashboard
* AI-Powered Financial Insights
* SIP & Compound Growth Learning
* Investment Scenario Modeling
* Firebase Authentication
* Multi-Currency Support
* Interactive Charts & Reports

---

## Tech Stack

* **Frontend:** Flutter (Dart)
* **Backend:** FastAPI (Python)
* **Database:** Firebase + SQLite
* **AI/ML:** Gemini API, Scikit-learn, Pandas

---

## Project Goal

FinWise aims to transform traditional expense tracking into an interactive financial learning experience. Instead of only tracking spending, the app helps users understand:

* Saving habits
* Investment fundamentals
* Wealth growth through compounding
* Personalized financial improvement strategies
